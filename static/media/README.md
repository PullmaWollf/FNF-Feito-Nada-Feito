# Arquivos fornecidos pelo usuário

- `cartman-kyle.mp3`: cópia do MP3 de South Park anexado pelo usuário, duração decodificada de aproximadamente 97,15 segundos. Não é uma composição criada pelo projeto.
- `cartman.png`, `kyle.png`: imagens de referência anexadas pelo usuário. As várias imagens repetidas de Kyle representam a mesma referência, usada uma vez.

Os personagens e o áudio pertencem aos respectivos titulares. Não se declara uma licença original sobre esses arquivos. O jogo aplica animações em Canvas e gera seu mapa a partir do áudio fornecido. Modelos de transcrição e seus pesos não são distribuídos no repositório.
